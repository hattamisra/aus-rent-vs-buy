## Large language model usage declaration

Large language models (LLMs) were used in this project through GitHub Copilot (including "Agent" semi-autonomous code generation) to create python scripts to download and process data for analysis.

LLMs were not used in other parts of this project, including:
* Literature review and finding data sources;
* Analysis of the processed data, including the formulation and creation of the analytical model;
* Visualising and writing up discussion of the results.
